# Documentation (`docs/`)

This directory maintains comprehensive project documentation, scientific methodology, architectural specifications, experimental protocols, decision logs, and references.

## Key Documents
- `PLAN.md`: Comprehensive master research plan, scope definitions, dataset specifications, task orders, and phased milestone roadmap (Phases 0 through 7).
- `DECISIONS.md`: Record of frozen architectural and algorithmic decisions with one-line justifications, alongside analysis of key project risks and mitigation strategies.
- `EXPERIMENT_MATRIX.md`: Complete matrix of experimental configurations (methods $\times$ task orders $\times$ seeds).
- `METRICS.md`: Rigorous mathematical formulations for all classification, continual learning, and efficiency metrics.
- `CONFIG_SCHEMA.md`: Documentation of configuration hierarchy and YAML parameters.
- `architecture/`: Diagrams detailing CNN block topology, expandable head dynamics, and LwF distillation mechanisms.
- `references/`: Comprehensive literature survey, citations, and benchmark references.
- `report/`: Drafts and components for final research project report and presentations.
