# Scientific References and Literature Survey (`docs/references/papers.md`)

This bibliography compiles the fundamental literature grounding this project's methodologies across continual learning, knowledge distillation, brain tumor MRI classification, and model explainability.

---

## 1. Continual Learning & Knowledge Distillation

1. **Learning without Forgetting (LwF)**
   - *Authors*: Zhizhong Li, Derek Hoiem
   - *Venue*: IEEE Transactions on Pattern Analysis and Machine Intelligence (TPAMI), 2017.
   - *Key Insight*: Introduces feature distillation using soft targets generated by the previous model iteration, preserving representations of historical tasks without retaining historical raw data.

2. **iCaRL: Incremental Classifier and Representation Learning**
   - *Authors*: Sylvestre-Alvise Rebuffi, Alexander Kolesnikov, Georg Sperl, Christoph H. Lampert
   - *Venue*: IEEE Conference on Computer Vision and Pattern Recognition (CVPR), 2017.
   - *Key Insight*: Demonstrates the limitations of pure distillation in class-incremental learning and introduces exemplar memory buffers with herding selection.

3. **Distilling the Knowledge in a Neural Network**
   - *Authors*: Geoffrey Hinton, Oriol Vinyals, Jeff Dean
   - *Venue*: NeurIPS Deep Learning and Representation Learning Workshop, 2015.
   - *Key Insight*: Temperature-scaled cross-entropy loss softens target output distributions, revealing dark knowledge and inter-class structural affinities.

4. **A Comprehensive Survey of Continual Learning: Theory, Method and Application**
   - *Authors*: Liyuan Wang, Xingxing Zhang, Hang Su, Jun Zhu
   - *Venue*: IEEE TPAMI, 2024.
   - *Key Insight*: Comprehensive taxonomy comparing regularization-based, replay-based, and architectural continual learning strategies.

## 2. Brain Tumor MRI Classification

5. **Brain Tumor Detection and Classification Using MRI Images**
   - *Dataset Release*: Masoud Nickparvar
   - *Source*: Kaggle / Mendeley Data, 2021.
   - *Key Insight*: Curates 7,023 MRI slices across glioma, meningioma, pituitary tumor, and non-tumor control classes with standard official partitions.

6. **Deep Learning for Brain Tumor Segmentation and Classification: A Review**
   - *Authors*: Geert Litjens et al.
   - *Venue*: Medical Image Analysis, 2017.
   - *Key Insight*: Outlines standard MRI preprocessing pipelines, including skull-stripping, intensity normalization, and contour-based bounding-box isolation.

## 3. Explainability and Architecture Profiling

7. **Grad-CAM: Visual Explanations from Deep Networks via Gradient-Based Localization**
   - *Authors*: Ramprasaath R. Selvaraju, Michael Cogswell, Abhishek Das, Ramakrishna Vedaldi, Devi Parikh, Dhruv Batra
   - *Venue*: IEEE International Conference on Computer Vision (ICCV), 2017.
   - *Key Insight*: Uses gradients flowing into the final convolutional layer to generate coarse 2D localization heatmaps highlighting discriminative image regions.
