# Project Assets (`assets/`)

This directory stores visual assets, documentation graphics, sample MRI test images for the interactive Gradio demo, and project promotional badges.

## Contents
- `banner.png`: Project header graphic and pipeline overview schematic.
- `demo_samples/`: Curated, anonymized sample brain MRI slices across all 4 diagnostic classes (`glioma`, `meningioma`, `pituitary`, `notumor`) used for one-click testing in the Gradio web interface.
- `demo.gif`: Animated demonstration of the Gradio interface performing inference and displaying real-time Grad-CAM attention maps.
